# 09. 품질·호환성·접근성 최종 검증

- 기준일: 2026-08-14
- 상태: 수동 실기기·시각·접근성·장애 검증 필요
- 범위: iPhone 전용, 세로 방향, iOS 17 이상

자동화된 언어·테마·Dynamic Type 스모크와 현지화 카탈로그 검사는 별도 회귀 테스트로 유지한다.
이 문서는 자동화가 대체하지 못하는 **출시 전 미완료 검증만** 추적한다.
테스트에는 가짜 계정과 테스트 데이터만 사용하고, 결과에는 비밀번호·토큰·실제 개인정보를 남기지 않는다.

관련 기준: [iOS 개발·테스트 명령](../../README.md), [Apple Accessibility](https://developer.apple.com/accessibility/), [Apple HIG Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

## 1. 기기·viewport 시각 QA

- [ ] 최소 한 대의 실제 iPhone에 **심사 후보와 같은 TestFlight 빌드**를 설치해 핵심 흐름을 완주한다.
- [ ] 작은 화면 `375×812`과 큰 화면 `402×874`에서 로그인, 홈, 캘린더, Todo, 친구·팀, 알림, 설정을 확인한다.
- [ ] 탭 바, 툴바, sheet의 최종 버튼, Safe Area, 홈 인디케이터와 Dynamic Island가 콘텐츠와 겹치지 않는다.
- [ ] 긴 제목·이름, 많은 일정·Todo, 빈 상태와 오류 상태에서도 잘림·가로 overflow가 없고 마지막 항목까지 스크롤된다.
- [ ] 키보드가 표시된 모든 입력 화면에서 필드, 저장·취소·완료 버튼에 접근하고 키보드를 닫을 수 있다.
- [ ] 사진·파일 선택, 카메라, 미리보기, 공유 sheet를 실제 iPhone에서 확인한다.
- [ ] App Store 정보가 iPhone 전용·세로 방향 지원 범위와 일치한다.

## 2. 언어·테마·Dynamic Type

핵심 흐름은 아래 조합을 작은 화면과 큰 화면에서 확인한다. 나머지 화면은 조합을 분산하되 한국어·영어와 Light·Dark가 모두 포함되어야 한다.

| 언어 | 테마 | 글자 크기 |
| --- | --- | --- |
| 한국어 | Light / Dark | 기본 / 최대 접근성 크기 |
| English | Light / Dark | 기본 / 최대 접근성 크기 |

- [ ] 번역 key나 개발자용 문구가 노출되지 않고, 한국어·영어의 버튼·탭·경고·오류 문구가 잘리지 않는다.
- [ ] Dark Mode에서 텍스트, 경계선, 선택·비활성 상태와 오류가 충분히 구분된다.
- [ ] 최대 Dynamic Type에서도 줄바꿈·확대·스크롤을 통해 모든 핵심 작업을 끝낼 수 있다.
- [ ] 시스템 테마와 앱의 `system/light/dark` 설정 변경이 즉시 반영되고 재실행 후 유지된다.

## 3. VoiceOver와 대체 조작

- [ ] 로그인부터 로그아웃까지 핵심 흐름을 VoiceOver만으로 완료한다.
- [ ] 제목, 입력, 버튼, 목록의 읽기 순서와 modal 진입·복귀 포커스가 시각적 구조와 일치한다.
- [ ] 아이콘 전용 버튼, 선택·읽지 않음·로딩·오류·비활성 상태가 한국어·영어로 의미 있게 읽힌다.
- [ ] 캘린더 날짜 셀이 날짜·오늘·선택 상태와 근무·일정·Todo 요약을 과도하지 않게 전달하며 월 이동 후 포커스를 잃지 않는다.
- [ ] Todo 순서·상태 변경을 드래그 없이 접근성 action으로 수행하고, 성공·실패·복구 결과를 인지할 수 있다.
- [ ] 삭제, 로그아웃, 회원 탈퇴와 같은 위험 동작의 대상과 결과가 명확히 읽힌다.

## 4. 44pt 터치 영역과 대비

- [ ] 탭 바, 알림, 추가, 닫기, 뒤로가기, 더보기 등 모든 주요 조작의 실제 hit target이 최소 `44×44pt`다.
- [ ] 작은 아이콘의 padding·`contentShape`가 적용되고 인접 조작 영역이 겹치지 않는다.
- [ ] 최대 Dynamic Type에서도 터치 영역이 축소되지 않는다.
- [ ] Light·Dark 모두에서 텍스트, 상태색, 오류, focus와 disabled 상태의 대비를 확인한다.

## 5. 네트워크·복구 시나리오

- [ ] 오프라인 첫 실행, 느린 연결, 요청 중 연결 중단에서도 앱이 멈추거나 종료되지 않는다.
- [ ] 일정·Todo·첨부 저장을 재시도해도 중복 생성되지 않고 입력 내용이 가능한 한 보존된다.
- [ ] `401`은 세션 갱신 또는 로그인 전환으로 끝나며 무한 재시도하지 않는다.
- [ ] `403`, `404`, `429`, `5xx`를 사용자가 이해하고 다음 행동을 선택할 수 있는 한국어·영어 문구로 표시한다.
- [ ] 첨부 업로드 취소·실패·재시도와 background 복귀 뒤 데이터 재조회가 안전하다.
- [ ] APNs 권한 거부·토큰 등록 실패가 앱의 나머지 기능 사용을 막지 않는다.

## 완료 조건

- [ ] 위 기기·언어·테마·글자 크기 매트릭스와 VoiceOver 핵심 흐름에 차단 결함이 없다.
- [ ] 44pt, 대비, 키보드, 첨부·공유 sheet를 실제 iPhone에서 검증했다.
- [ ] 네트워크·인증·서버 오류에서 크래시, 데이터 유실, 중복 저장과 무한 재시도가 없다.
- [ ] 검증한 앱 버전·빌드, iOS 버전, 기기와 미해결 결함을 출시 승인 기록에 남겼다.
